# Шпаргалка по Git и GitHub

Пополняется на каждом этапе. Здесь — только то, что мы реально использовали в этом проекте.

## Основные понятия

| Понятие | Простыми словами |
|---|---|
| **Репозиторий** | папка проекта + вся история её изменений |
| **Коммит** | сохранённый снимок изменений с подписью «что и зачем» |
| **Ветка** | параллельная линия истории; правки в ней не трогают `main`, пока их не вольют |
| **`main`** | главная ветка — рабочая, проверенная версия проекта |
| **Remote / `origin`** | копия репозитория на GitHub |
| **Push** | отправить свои коммиты на GitHub |
| **Pull** | забрать новые коммиты с GitHub |
| **Pull Request (PR)** | запрос «влей мою ветку в `main`» — с диффом, обсуждением и проверками |
| **Issue** | задача или проблема на GitHub |
| **Milestone** | веха — набор задач одного этапа |
| **Тег / Release** | метка версии (`v0.1.0`) и страница релиза с файлами |

## Этап 0. Подключение к GitHub

| Команда | Что делает |
|---|---|
| `brew install gh` | ставит GitHub CLI — программу для работы с GitHub из терминала |
| `gh auth login --git-protocol ssh --web` | входит в аккаунт GitHub через браузер и загружает SSH-ключ |
| `ssh -T git@github.com` | проверяет, что GitHub узнаёт ваш компьютер по SSH-ключу |
