# Roadmap — «Мой дацан»

> Этапы разработки по порядку. Требования к продукту — в [PRD.md](PRD.md).
>
> **Как читать этот файл.** Каждый этап — это **Milestone** (веха) на GitHub. Каждый пункт в «Задачах» — отдельный
> **Issue** (задача). Каждая задача делается в своей ветке и попадает в `main` через **Pull Request**.
> В конце этапа ставим **тег** версии и делаем **GitHub Release**.
> В графе «Git-навык» — что из Git/GitHub мы осваиваем на этом этапе.

## Общий цикл работы над задачей

```
Issue #N на GitHub
   │
   ▼
git switch main && git pull          ← взять свежий main
git switch -c feature/N-кратко       ← новая ветка под задачу
   │  … правки …
   ▼
git add … && git commit -m "feat: …" ← сохранить шаг (можно несколько коммитов)
git push -u origin feature/N-кратко  ← отправить ветку на GitHub
gh pr create                         ← открыть Pull Request («Closes #N»)
   │  просмотр диффа, проверка
   ▼
gh pr merge --squash --delete-branch ← влить в main, Issue закроется сам
git switch main && git pull          ← обновить локальный main
```

## Этап 1. Скелет монорепо — `v0.1.0`

**Цель:** проект запускается одной командой, видны 5 вкладок-заглушек.

Задачи:
- [ ] Корневой `package.json` с npm workspaces (`server`, `user`, `admin`, `shared`) и скриптами `dev`, `build`, `test`.
- [ ] `server/`: Express + TypeScript, `GET /api/health`, SQLite (better-sqlite3) с файлом `server/data/datsan.db`.
- [ ] `user/`: React + Vite, нижняя навигация на 5 вкладок (Практика · Хуралы · Философия · Зурхай · Божества), тёмная тема, палитра.
- [ ] `admin/`: React + Vite, пустой экран.
- [ ] Прокси Vite `/api` → `localhost:3001`; `.claude/launch.json` для встроенного браузера.
- [ ] Сверка вёрстки с «Я стоик» во встроенном браузере (мобильный экран).

Готово, когда: `npm run dev` открывает приложение, вкладки переключаются, `/api/health` отвечает `ok`.
