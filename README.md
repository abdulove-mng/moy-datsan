# Мой дацан

Приложение для традиционных буддистов Бурятии, Тывы и Калмыкии: значение хуралов, зурхай, буддийские божества
и через них — философия: книга «Тибетский буддизм с самых основ» и ежедневная практика.

- Что делаем — [PRD.md](PRD.md)
- В каком порядке — [roadmap.md](roadmap.md)
- Как устроено — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Шпаргалка по Git — [docs/GIT_GUIDE.md](docs/GIT_GUIDE.md)

## Запуск

Появится на этапе 1 (`npm install` → `npm run dev`).
